Copy saves between PS2 memory card images

Open two card images, select complete saves on the source, then copy them to the destination. Download the destination card to keep the result.

Choose your cards

You need two standard 8 MiB memory card images. Keep backups of both. PS2STK reads local files and edits working copies in browser memory. It does not connect directly to physical memory cards.

The source supplies the saves. The destination receives them. If you only have a save package, use the import guide instead.

Copy the saves

  1. Open the source in Card A.

    Choose Open memory card and select the source image.

  2. Open the destination in Card B.

    Use the header's Open memory card action to open the second image. You can use New memory card to create an empty destination instead.

  3. Select saves on Card A.

    Use the checkboxes to select the complete saves you want to copy. A save includes its directory and every file inside it.

  4. Choose Copy to B.

    The review shows the transfer direction, destination space, and each selected save. Check the direction before applying.

  5. Resolve conflicts and apply.

    For a matching destination directory, keep Skip or choose Replace entire save. Then choose Apply copy choices.

  6. Download Card B.

    Use Download card on the destination. To choose another card extension, use Download as.

You can also copy in the other direction with Copy to A. The source stays unchanged. A successful batch is one Undo step on the destination; Redo can restore it.

Download before leaving. Refreshing or closing the toolkit discards cards and edits. A downloaded package is not a download of the edited card.

Conflicts and capacity

Conflicts use the save's directory name, not just its displayed game title. Skip preserves the existing destination save. Replace entire save replaces it as a whole, including its metadata, and removes destination-only files. Files are never merged.

The capacity check includes directory space and the space reclaimed by replacements. If the chosen batch cannot fit, both cards stay unchanged. Saves you explicitly skip are excluded from the batch.

Copying does not rename saves, convert game regions, or remove protection flags. Game-load validation on PCSX2 and PS2 through MemCard PRO2 remains pending.
