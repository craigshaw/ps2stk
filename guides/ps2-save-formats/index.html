PS2 save formats explained

A card image holds a whole memory card. A save package holds one save. Choose the output for the task you need to complete.

On this pageMemory card imagesSave packagesChoose your outputSupported limits

Memory card images

A card image represents a memory card file system and all its contents. PS2STK opens standard 8 MiB images, with or without spare bytes. Common filenames end in .ps2, .mc2 or .bin. The extension alone does not prove the layout.

When downloading, PS2STK writes .ps2 with error-correction (ECC) spare bytes. It writes .mc2 and .bin without them. Use Download as to select an extension. This affects the downloaded layout, not your working card or Undo history.

Card images are useful when you need to keep several saves together or preserve a save with nested folders.

Save packages

A save is one directory and its contents. A save package puts that complete save into one transfer file. A game can use several separate saves.

PS2STK checks package integrity where the format provides it. Missing metadata uses documented defaults, shown in the import review. MAX and PSV exports require acknowledgement of metadata loss.

ZIP and RAR are archive wrappers. PS2STK can open supported packages inside them, including packages in subfolders. Choose one package when there are several. Other archive files are reported and left out. Raw save folders and nested archives are unsupported.

PS2 PSV is different from PS1 PSV, native PS3 saves, and encrypted PS2 Classics card images. Those inputs are outside this tool's scope.

Choose your output

  • Keep the whole card: use Download card or Download as.
  • Transfer one save: select it and use Export selected save. PSU is the default. Choose MAX or PSV only when your destination needs that format.
  • Get exact file bytes: select a save file and choose Dump file. A raw file has no package wrapper.
  • Keep a save's folder structure: choose Export selected save, then Raw files to folder in Chrome or Edge when directory access is available. Choose a new save folder; existing folders are not merged or overwritten.

Exporting a package or dumping files does not download the complete card. If the card has edits you want to retain, download it too.

To change package formats with the current tool, import the save into a card, then export the selected save. There is no standalone package converter.

Supported limits

PS2STK opens at most two standard 8 MiB cards. It supports flat save packages, not packages with nested folders. Larger cards, damaged-card repair, region conversion and game-specific editing are outside scope.

Archives must be unencrypted and contained in one file. ZIP supports stored and deflated members, without ZIP64. RAR supports RAR4 and RAR5 compression version 0, including solid archives, with dictionaries up to 64 MiB. Archives are limited to 16 MiB input, 256 entries, 16 MiB per member and 32 MiB total extracted bytes. Unsafe paths, links, incomplete data and invalid checksums are rejected.

Format checks verify bytes and structures. They do not prove that a destination game or device accepts the result. PCSX2, MemCard PRO2 and PS3 game-load validation remains pending.
